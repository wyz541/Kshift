# ADR 历史模板

> 结论：新决策禁止使用本模板。新决策进入 Research 或 Task Issue，当前规则进入 Active Spec。

## 1. 替代流程

1. 在 Discussion 或 Issue 中形成问题。
2. 在 Research 或 Task Issue 中记录选项、证据和结论。
3. 更新受影响的 Active Spec。
4. 更新合同、模板和检查。
5. 在 PR 中提供实际验收证据。

## 2. 历史用途

- 读取历史 ADR 的结构。
- 核对 ADR 到 Spec 的迁移目标。
- 追溯旧决策的原因。
