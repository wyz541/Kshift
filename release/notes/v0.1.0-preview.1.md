## 安装

每个平台的使用步骤以对应 fragment 和 Release evidence 为准。未生成运行证据的步骤不写为已验证。

## 已知限制

- 仅限内网。
- 不支持外部导入。
- Preview 资产可以使用 `ad-hoc` 或 `unsigned` 签名。
- 安装、升级、回滚和无障碍证据可能不完整。

## 回滚

停止使用 Preview build。安装上一个已批准 build。数据库 schema 不兼容时，恢复迁移前备份。
