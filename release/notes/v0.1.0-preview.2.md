# Kshift v0.1.0 Preview 2

## 状态

这是内部 Preview。Preview 不是 Stable 发布。

## 平台

| 平台 | 最低版本 | 本次资产 |
| --- | --- | --- |
| macOS | 26.0 | unsigned DMG and ZIP |
| iOS | 26.0 | unsigned IPA |
| Server | PostgreSQL 18.x | macOS arm64 server bundle |
| Source | 不适用 | source archive |

所有平台资产来自同一个 source commit。

## 安装

1. 下载 Release manifest 和 `SHA256SUMS`。
2. 验证所有资产的 SHA-256。
3. 验证 GitHub attestation。
4. 使用对应 fragment 中的平台说明安装。

## 已知限制

- 仅限内网。
- macOS 和 iOS 资产没有分发签名。
- 没有 notarization、TestFlight、干净机器安装或物理设备安装证据。
- Stable Release 门禁没有通过。

## 回滚

停止使用 Preview build。安装上一个已批准 build。数据库 schema 不兼容时，恢复迁移前备份。
