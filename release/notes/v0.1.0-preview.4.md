## 状态

这是 Internal Preview。它不是 Stable Release，也不会进入 Stable update feed。

## 平台

| 平台 | 最低版本 | 本次资产 | 安装边界 |
| --- | --- | --- | --- |

## 本次变更

- 合并 Windows 任务编辑、版本冲突和只读 fixture 路径。
- macOS Stable policy 允许 ad-hoc 签名，Developer ID/notarization 改为可选。
- 增加当前 `v0.1.0` qualification 证据：30 分钟 2× 负载、LaunchAgent 重启、PostgreSQL 备份恢复和生命周期测试。
- Internal Preview 的 macOS 资产改为 ad-hoc 签名并验证。

## 安装

1. 下载 Release manifest 和 `SHA256SUMS`。
2. 验证所有资产的 SHA-256。
3. 验证 GitHub attestation。
4. macOS 使用 DMG 或 ZIP；首次打开可能需要受控内网环境的 Gatekeeper 处理。
5. iOS unsigned IPA 不得描述为可安装的 iPhone 构建。

## 已知限制

- 仅限内网。
- iOS 没有分发签名、TestFlight、设备安装或升级证据。
- macOS 没有 Developer ID、notarization 或干净外部机器安装证据。
- Stable Release 门禁没有通过。
- Preview 不会出现在 `/releases/latest` 的 Stable update feed 中。

## 回滚

停止使用 Internal Preview。安装上一个已批准 build。数据库 schema 不兼容时，恢复迁移前备份。Preview 修复使用新的 preview 编号，不移动已发布标签。
