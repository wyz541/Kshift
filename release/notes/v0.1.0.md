# Kshift v0.1.0

## 状态

这是 Stable 发布说明模板。当前 R4/R5 门禁未通过，禁止 Promote。

## 平台

| 平台 | 最低版本 | 分发 |
| --- | --- | --- |
| macOS | 26.0 | 签名 DMG 或 ZIP |
| iOS | 26.0 | TestFlight 或内部签名 IPA |
| Server | PostgreSQL 18.x | 内网 macOS 安装包 |

## 安装

1. 备份数据库。
2. 验证 Release manifest 和 `SHA256SUMS`。
3. 验证 GitHub attestation。
4. 安装 server bundle。
5. 执行迁移前备份检查。
6. 安装 macOS 应用。
7. 安装 iOS 内部 build。
8. 运行健康检查和 P0 流程。

## 已知限制

- 仅限内网。
- 不支持外部平台导入。
- 不提供高可用数据库承诺。
- 4 小时 RPO 和 4 小时 RTO。
